# VERSIONING

## Service

Smart Campus Notification Service API

## Current Version

v1.0.0

## Versioning Policy

Project sử dụng Semantic Versioning:

- MAJOR:
  Thay đổi breaking change trong API contract.

- MINOR:
  Thêm endpoint mới hoặc mở rộng response schema.

- PATCH:
  Sửa lỗi tài liệu, mock response hoặc validation nhỏ.
